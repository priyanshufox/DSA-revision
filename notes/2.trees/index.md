# Trees

## Key Concepts
- **TreeNode** — binary tree node with `val`, `left`, `right`
- **DFS on trees** — recursion naturally models tree traversal; base case is `null` node
- **Height** — max depth from a node to a leaf; computed bottom-up via recursion
- **Balanced tree** — height difference of left and right subtree ≤ 1 at every node
- **Structural equality** — two trees are the same if values and shape match recursively
